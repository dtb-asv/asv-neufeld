ASV NEUFELD – SPIELPLAN GENERATOR

1. Diese Dateien nach C:\Users\DTB\asv-neufeld kopieren.
2. Excel-Datei nach Excel2\Terminefussball_2026_HerbstV2.0.xlsx legen.
3. Optional background.jpg in den Hauptordner legen.
4. Einmal installieren:
   pip install -r requirements.txt
5. Danach ASV_Spielplan_Starten.bat doppelklicken.

Die PDFs werden im Ordner output erstellt.
